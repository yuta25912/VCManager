# VCManager プラグイン

ボイスチャンネルの高度な管理機能を追加します。

## ✨ 機能
- **🔊 VC全員移動**: 特定のチャンネルにいるユーザーを全員別の部屋へ移動させます。
- **👤 VC特定ユーザー移動**: リスト形式で指定したユーザーのみを移動させます。
- **🔐 VC権限ロック**: 「表示・接続・発言」の権限を、ロールやユーザーごとに個別に「許可・拒否」設定できます。

## ⚙️ 使い方
このプラグインをインストールすると、ツールボックスに「🔊 VCManager」カテゴリーが追加されます。

### 注意事項
- ボットに「メンバーを移動」や「権限の管理」の権限が必要です。
- ユーザーを移動させるには、そのユーザーがすでにどこかのボイスチャンネルに接続している必要があります。

## 🚀 インストール方法
1. [Easy Discord Bot Builder](https://edbplugin.github.io/easy-bdp/) を開きます。
2. プラグインから以下のURLを指定してインストールしてください：
   `https://edbplugin.github.io/easy-bdp/editor/index.html?install-plugin=yuta25912%2FVCManager%40master`
